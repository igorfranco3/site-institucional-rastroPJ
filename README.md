Rastro PJ: site institucional

Site institucional do Rastro PJ, plataforma que transforma as publicações mensais do CNPJ em histórico empresarial dos 35 municípios do Triângulo Mineiro.

O site apresenta o produto, mostra suas telas e leva a pessoa interessada a solicitar uma demonstração. Ele é separado do portal do MVP: não tem login, não acessa banco de dados e não reproduz funcionalidades do sistema.

Tecnologias
HTML5 e CSS3 puros
Sem JavaScript, sem framework, sem npm e sem etapa de build
Fonte Inter via Google Fonts (sem internet, o navegador usa a fonte do sistema)

Não existe nada para instalar. Basta um navegador.

Como rodar
1. Baixe o projeto

Com Git:

bash
git clone https://github.com/igorfranco3/site-institucional-rastroPJ.git
cd site-institucional-rastroPJ

Sem Git: na página do repositório, clique em Code → Download ZIP e extraia a pasta.

2. Abra o site

Escolha uma das opções abaixo.

Opção A: duplo clique (mais simples)

Abra a pasta do projeto e dê dois cliques no index.html. O site abre no navegador padrão.

Opção B: VS Code + Live Server (recomendada para quem vai editar)

Abra a pasta do projeto no VS Code (File → Open Folder).
Instale a extensão Live Server (autor: Ritwick Dey).
Clique com o botão direito no index.html → Open with Live Server.

O navegador recarrega sozinho toda vez que você salva um arquivo.
